# MARSHGO 9.0 — MOTION DESIGN BIBLE (WAVE D4–D7, D9)

**Дата:** 04.11.2026  
**Цільовий фреймрейт:** Стабільні 60 FPS на мобільних пристроях (P95 frame time < 16.6ms)  
**Апаратне прискорення:** Виключно `transform` та `opacity`  

---

## 1. П'ЯТЬ РІВНІВ РУХУ (MOTION TAXONOMY)

### L1 — Micro Motion (100–180ms)
- **Тактильний відгук (Press Feedback):** `active:scale-[0.98]` або `active:scale-[0.96]` із кривою `cubic-bezier(0.2, 0, 0, 1)`.
- **Фокус і перемикачі:** плавна зміна обводки та фонового підсвічування за 140ms.
- **Іконки:** короткий морфінг або обертання при взаємодії (наприклад, кнопка згортання/розгортання шторки).

### L2 — Component Motion (180–300ms)
- **Поява карток маршрутів:** каскадний stagger (`animation-delay: calc(index * 40ms)`), що не перевищує 200ms сумарно.
- **Модальні вікна та випадаючі списки:** плавний виїзд знизу (`translateY(10px) → translateY(0)`) та розкриття непрозорості.
- **Снеп шторки (Bottom Sheet):** плавний пружинний доводчик до найближчого зі станів (`collapsed`, `summary`, `half`, `full`).

### L3 — Screen Transitions (240–380ms)
- **Пошук → Результати → Карта:** просторова безперервність (Continuity Flow).
- Збереження ключових маркерів Origin/Destination на екрані при переході від форми пошуку до карти.

### L4 — Spatial Motion (300–650ms)
- **Фокусування камери MapLibre:** використання методу `camera.easeTo()` або `camera.fitBounds()` із розрахунком безпечних полів під нижню шторку (bottom padding).
- **2D/3D перемикання:** плавний нахил площини (pitch 0° ↔ 60°) за 500ms без перемонтування геометрії.
- **Перериваність жестом:** будь-який дотик пальця до карти миттєво перериває програмну анімацію камери.

### L5 — Realtime Motion (Data-Driven Interpolation)
- **Плавна інтерполяція GPS:** рух маркера транспорту розраховується як лінійна інтерполяція між двома підтвердженими телеметричними координатами.
- **Захист від імітації:** при втраті зв'язку або застарілих даних (STALE) штучний рух негайно зупиняється.

## 2. PREFERS-REDUCED-MOTION CONTRACT

Для користувачів з увімкненою системною опцією зменшення руху:
```css
@media (prefers-reduced-motion: reduce) {
  *, ::before, ::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```
Усі переходи між екранами та станами відбуваються миттєво, зберігаючи 100% функціональності та доступності.
