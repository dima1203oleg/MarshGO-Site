# Design 3.0 — три концепції (PROPOSED)

Статус: **PROPOSED**. Не затверджено. Production-код не змінюється до Gate A1.
Токени: `../tokens/DESIGN_TOKENS.json` (контраст 32/32 пар — VERIFIED скриптом `check-contrast.py`).
Макети: `../mockups/{A|B|C}-{home|search|results}-{light|dark}.png` (18 шт., статус — див. VISUAL_INDEX нижче).

## A — Graphite Horizon
- **Ідея:** преміальний автомобільний цифровий продукт.
- **Поверхні:** матовий графіт, один інтелектуальний синій для дій і вибраного маршруту.
- **Типографіка:** щільніша, великі цифри маршруту (28/32, 800).
- **Кнопки:** Horizon Capsule 56 px, високий контраст, мінімум декору.
- **Карта:** темна схема за замовчуванням, виразні маркери транспорту.
- **Ризик:** вдень на сонці темна гама гірша; потребує дуже якісної світлої теми.

## B — Clarity Flow
- **Ідея:** найзрозуміліший щоденний застосунок.
- **Поверхні:** світлі, повітряні, просторі картки, радіус 18.
- **Типографіка:** найбільша; критичні значення ≥14 px, ціль 16 px для тіла.
- **Кнопки:** touch target 48–56 px, великі зони плиток 112+ px.
- **Карта:** мінімалістична, приглушені неактивні лінії.
- **Ризик:** може виглядати «менш преміально», слабший характер бренду.

## C — Transit Pulse
- **Ідея:** інтелектуальна мобільність майбутнього.
- **Поверхні:** Blue/Violet/Cyan акценти, фірмові траєкторії (Transit Thread).
- **Motion:** кінетичні переходи, але лише на подіях (вибір маршруту, snap); без нескінченних GPU-анімацій.
- **Ризик:** перенасичення кольором, найвища вартість реалізації, складніше забезпечити контраст у градієнтах.

## Рекомендація: MARSHGO Horizon Flow (PROPOSED)
Читабельність і структура B + преміальні поверхні та темна тема A + вибіркова анімація маршруту з C. Автоматично не затверджується.

## Фірмові елементи (спільні для всіх)
Horizon Capsule · Transit Thread (пропорційні сегменти, очікування ≠ поїздка) · MarshPass Fold · Smart Route Surface · Floating Route HUD · Intelligent Transport Marker.

## Інваріанти (не змінюються між концепціями)
- Нижня панель: Головна | Пошук | + | Поїздки | Профіль.
- Головна без полів «Звідки/Куди»; 4 дії: Навігація, Опублікувати поїздку, Карта транспорту, Знайти маршрут.
- 12 категорій 4×3; метро Львова неактивне з поясненням.
- Результати: одна карта + sheet із 4 snap-станами (12/34/64/100%).
- Невідомий тариф → «—» і «Тариф невідомий», не 0 грн.
- Усі демо-дані мають мітку «ДЕМО · НЕ LIVE».
