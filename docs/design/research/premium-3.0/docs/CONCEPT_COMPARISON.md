## Обґрунтування
- **B** виграє за читабельність, доступність, продуктивність і простоту — важливо для вуличного використання на сонці.
- **A** додає преміальність і сильну темну тему, але світла тема потребує окремої якості.
- **C** найвпізнаваніша, але найризикованіша для контрасту, GPU і складності.
- **Horizon Flow** — комбінація; ціна — трохи вища складність, ніж у B.

## Вибір для власника
