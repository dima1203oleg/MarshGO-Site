## 2. Що підтвердилося як робоче

`POST /auth/register` **201** → `/users/me` 200 → `/bookings` `/vehicles` `/users/me/blocks`
`/demands/mine` `/demands/mine/navigation-matches` `/conversation-unread-counts`
`/users/me/verification` `/mobility/providers` `/journeys/me` усі 200,
`POST /realtime/ticket` 201. Негативний контроль входу: «Невірний email або пароль».
`pageErrors: []` в усіх прогонах.

Екрани: головна (`h1` «Попутники знайдуться на твоєму маршруті»), пошук із живим
геокодером («Львів, Львівська міська громада … Україна», «Київ, Україна»),
результати (5 карток), мапа маршруту з реальними тайлами в **обох** темах,
«Мої поїздки», «Профіль». Усі 12 категорій транспорту присутні; 5 із них
чесно позначені «Недоступно для побудови маршруту в цьому районі» (Таксі, Метро,
Велосипед, Каршеринг, Трансфер).

**Жест панелі — робочий і точний.** `routeSheetHeights(844)` дає
collapsed 253.2 / half 316.5 / expanded 672. Виміряно на живому DOM:
317 → 672 → 317 → 253 → 317 px за п'ять перетягувань, тобто кожен чоп збігається
з формулою з точністю до округлення.

## 4. Дві самопоправки (щоб це не повторили як «факт»)

- «Базові тайли карти не налаштовані» на першому прогоні — **не дефект продукту**, а
  мій неповний env: без `VITE_MAP_TILE_URL` застосунок документально показує
  геометрию дороги без шару вулиць. Після передачі RC-значень мапа відрисувала тайли.
- «Кнопки перекривають текст картки на 100 %» — мій пробусчитував кнопку-контейнер
  картки (`aria-label="Відкрити маршрут: …"`), яка навмисно накриває весь блок.
  Справжнє зіткнення окремих круглих іконок з рядком тарифу видно на кадрі, але
  окремою геометрією ще **не ізольоване** → поки `NOT_VERIFIED`.
